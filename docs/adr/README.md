# Architecture Decision Records

ADRs registram decisões arquiteturais duradouras, suas alternativas e consequências.

## Quando criar

Crie uma ADR ao alterar contratos, fronteiras de módulos, tecnologia estrutural, persistência, segurança, estratégia de integração ou compatibilidade.

## Nome

```text
NNNN-titulo-curto.md
```

## Estrutura

```markdown
# ADR NNNN — Título

- Status: proposta | aceita | substituída | rejeitada
- Data: AAAA-MM-DD
- Responsáveis: nomes ou papéis

## Contexto
## Decisão
## Alternativas consideradas
## Consequências
## Plano de migração
```
